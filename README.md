### Overview
This project is a simple Todo List application built using Django. It allows users to register, log in, and manage their tasks efficiently. Users can add, delete, and mark tasks as completed.

### Features
- User registration and authentication
- Add new todo items
- View list of todos with details
- Mark todos as completed
- Delete todos
- User profile management

### Technologies Used
- Django: Web framework for building the application
- PostgreSQL: Database for storing user and todo data
- HTML/CSS: For front-end design
- Bootstrap: For responsive design
- Font Awesome: For icons
